# RSI Lab

浏览器端的受限 RSI 教学实验，静态 HTML/CSS/JavaScript，无需 API 密钥。

## 运行

在本目录执行 `npm start`，访问 http://localhost:5173 。执行 `npm test` 检查算法。

每次单代运行会同时训练 RL、验证 RSI 候选，并测量三个智能体。模式标签选择要回放和查看的智能体。暂停停止后续代数，当前代回放完成后停下。新地图只替换演示地图。刷新或重置清空数据。

## 实验边界

RSI 只搜索预设算法与参数，不生成代码或发明新算法。训练、逐代验证、固定测试、演示地图使用分离的种子区间。测试不参与候选选择。每图最多 240 次邻居检查，离线训练和验证成本不在该预算内。RL 使用局部特征，搜索使用完整地图；该比较用于教学，不是公平能力排名。

当前版本只在内存保存数据。外部字体无法加载时使用系统字体。

## 文件

- dist/index.html：页面结构与实验说明
- dist/style.css：响应式界面
- dist/engine.js：种子地图、搜索、Q-learning 和评估
- dist/app.js：实验控制与绘制
- tests.mjs：合法路径、预算、深度、可重复性和评估隔离检查

源码仓库：https://github.com/Coldplay-now/rsi-demo

本项目可由任意静态服务器托管 `dist/` 目录。
