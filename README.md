# RSI Lab 2

统一 5×5 局部观察、访问记忆和线性 Q 学习器的预算实验。包括固定规则、固定训练方法 RL、随机调参和诊断规则调参（受限 RSI 模拟）。

运行 `npm start` 后访问 http://localhost:5173 。运行 `npm test` 执行预算、路径、观察隔离、确定性和测试隔离检查。

每轮每组分配 6440 次环境行动上限，候选训练和验证全部计入；剩余额度作废。结束后才运行独立测试，随后锁定训练。可切换种子重复实验。当前演示展示完整轨迹及结束位置，浅色标记当前位置的可见区域。

实验局限：环境行动预算不代表等 CPU 成本；模型采用局部特征的线性近似；改进规则是预设规则，不会自我重写。绕路测试采用单一蛇形结构，不应把重复地图视作独立样本。多种子统计需逐次记录，本版不自动汇总置信区间。完整协议在网页说明中。

`dist/lab2.js` 是实验引擎，`dist/ui2.js` 是页面控制。旧版 engine.js/app.js 保留供历史对照，当前页面不加载。
